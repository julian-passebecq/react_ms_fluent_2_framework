Do not make React the chart grammar. D3 remains reusable outside React.

Power BI?Keep a platform adapter.

Basic marks can generate pbiviz starters. Advanced marks require pattern-specific data roles, selection and tooltip adapters rather than a false generic fallback.

Fabric / Databricks?Use them as data + notebook targets.

Spark does heavy work; D3 receives compact results through HTML.

AI?Generate specs before code.

If an existing pattern fits, create data mapping + spec only. Add renderer code only when a new reusable behavior is genuinely missing.
