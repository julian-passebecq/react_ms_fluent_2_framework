## V2 policy

Import the course for reading/explanation only.

Allowed:

- Markdown/prose;
- PySpark code;
- static saved output;
- data tables/images;
- ConceptMotion figures for partition/shuffle/transform/streaming/Delta concepts;
- quiz/review;
- copy/download/open-external actions.

Not allowed in V2:

- Spark execution inside the website;
- local cluster management;
- Spark Connect service;
- Kubernetes/Minikube/Kind orchestration;
- background jobs;
- fake run output.

`00_colab_setup.ipynb` is useful evidence that external Colab usage is already part of the source course. Keep external runtime launchers optional and clearly separate from the static site.
