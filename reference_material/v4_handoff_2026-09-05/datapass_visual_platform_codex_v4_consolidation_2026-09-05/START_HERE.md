# Start here

## Mission

Turn V3 from a technically strong multi-consumer platform into a visibly coherent, professional product family.

V4 should feel like a consolidation release:

```text
V3 proved reuse
   ↓
V4 audits repetition
   ↓
extracts only proven shared patterns
   ↓
removes developer/provenance noise from consumer UI
   ↓
raises Fluent 2 + editorial visual quality
   ↓
improves a few high-value interactive explanations
   ↓
strengthens AI/VS Code authoring ergonomics
```

## Hard baseline

Do not rebuild or replace V3. Preserve all existing contracts, IDs, persistence keys, deterministic imports, privacy gates, lazy Monaco behavior, source attribution, Storybook, legacy app, and all green QA unless a migration is explicitly documented.

The platform currently has seven application entry points:

- Studio / Visual Sandbox
- Formation
- Code Sandbox
- Code Interview
- Algorithm Atlas
- Architecture Atlas
- Pilot Center

V4 adds **no new end-user application by default**.

## First action

Before editing code, produce a short audit matrix of each V4 target as:

- DELIVERED already
- PARTIAL
- MISSING
- CONFLICTING

Then implement only the real delta.
