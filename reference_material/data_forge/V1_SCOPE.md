# V1 Scope

## Must have

- C#/.NET solution
- Contoso V2 adapter/reuse strategy
- higher-level ProjectSpec
- customer-satisfaction scenario
- shipment/return/support/review extensions
- deterministic problem injection
- truth manifest
- CSV/Parquet/Delta
- Bronze/Silver/Gold definitions
- star-schema metadata
- KPI catalog
- ML signal/leakage metadata
- SQL starter/reference
- PySpark starter/reference
- dbt project
- Airflow DAG
- Fabric/ADF reference output
- Databricks reference output
- BigQuery/Dataform output
- Power BI handoff
- CLI
- React front end
- project ZIP download
- tests.

## Good V1.5

- Azure-hosted demo
- Docker
- Terraform
- Container Apps Jobs for larger generation
- project gallery/thumbnail
- lightweight D3 DAG/architecture view
- moving-table concept demos.

## Not V1

- Kubernetes/AKS runtime
- full local Airflow
- full dbt execution platform
- full Fabric simulator
- full Databricks simulator
- drag/drop pipeline authoring
- multi-user code sandbox
- Power BI report editor.


## Reference repository policy

The supplied diagram/chart/Fabric repositories are research references.

Do not:
- vendor draw.io
- vendor Excalidraw
- add Python diagrams
- add Cloudcraft API
- add mobile chart libraries
- add a free-form diagram editor

unless a later requirement clearly justifies them.

V1 uses:
- Fluent UI
- Mermaid
- D3 selectively
- Monaco
on top of React.
