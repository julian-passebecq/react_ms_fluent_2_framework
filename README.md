- the locked React/Fluent/ConceptMotion architecture;
- Challenge Workbench requirements;
- Orchestration Workbench / WorkflowSpec requirements;

- future Narrative Story/GeoStory and modern Power BI D3 roadmaps;

The important scope rule is simple:

**V1.1 builds the shared Fluent + ConceptMotion + source-aware knowledge foundation. It does not build live monitoring, code-analysis services, D3 GeoStory or the Power BI D3 v2 layer.**
